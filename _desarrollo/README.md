# Herramientas de desarrollo (OPCIONAL)

**No necesitas nada de esta carpeta para publicar ni para editar textos, colores de contenido o config.js.**
GitHub Pages no publica esta carpeta (empieza por `_`).

Solo úsala si:
- Agregas clases nuevas de Tailwind en los HTML → `npm install` y `npm run build:css`
- Actualizas la versión del SDK de Firebase → `npm run build:firebase`
- Quieres probar las reglas de seguridad en tu PC (requiere Java) → `npm run test:rules`
